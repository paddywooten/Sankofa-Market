Email setup — five minutes, once

Every email Sankofa Market sends — receipts, sale alerts, delivery notices, the welcome message — goes through one free EmailJS account. You only need three values from it, and they are typed into the Emails page, not here.

Why this page exists: the key that has been on file (nQCOm9xJnMIZHqmIW, service service_ud6z4l6) is rejected by EmailJS with “Account not found”, so no email has actually been delivered yet. It needs to be replaced with the key from your own EmailJS account. Nothing else is broken.

Step by step

1
Sign in at dashboard.emailjs.com. If you have never used it, create the free account with sankofamarketgh@gmail.com.
2
Email Services → connect Gmail (sankofamarketgh@gmail.com). Copy the Service ID — it looks like service_ud6z4l6.
3
Email Templates → New Template. Name it sankofa_receipt.
4
Set the Subject to exactly {{subject}}. Set To Email to {{to_email}} and From name to {{site_name}}.
5
Switch the body to Code view and paste the block at the bottom of this page (there is a copy button). Save.
6
Copy the Template ID from the template list — it looks like template_xxxxxxx.
7
Account → General → copy the Public Key — one word of about 18 letters and numbers.
8
Open the Emails page, paste the three values, press Save, then press Send test email. If anything is still wrong the provider's exact answer appears on that page.

The free EmailJS plan allows 200 emails a month. If the marketplace outgrows that, the sender is a single function, so moving to another provider is a small change — ask and it can be done.

Email never blocks money. If sending fails, the payment, refund or withdrawal still completes; the failure is only logged and shown on the Emails page.

Admin pages are hidden from search engines and require an admin sign-in.
