## 🎯 **HOW IT WORKS**

### **For Buyers:**
1. **Browse** - See all products (marketplace + Sankofa Store)
2. **Search** - Search for anything with filters
3. **Filter** - Filter by category, price, condition, location, seller type
4. **Buy** - Purchase from trusted sellers

### **For Sellers:**
1. **List** - Take photos, write description, set price
2. **Connect** - Chat with buyers, negotiate
3. **Sell** - Complete transaction securely

### **Sankofa Store (Your Store):**
1. **Add Products** - Mark with `isSankofaStore: true`
2. **Special Badge** - "Official Store" badge appears
3. **Priority** - Your products appear first
4. **Trust** - Customers trust official store products
