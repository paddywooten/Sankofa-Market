1

Create Firebase Project

⏱ ~3 minutes

🌐 Open Firebase Console

Go to console.firebase.google.com and sign in with your Google account.

➕ Click "Add project"

You'll see this button on the main Firebase dashboard page. Click it to start creating a new project.

✏️ Name your project

Type: sankofa-market

ℹ️
If "sankofa-market" is already taken, Firebase will automatically add numbers to make it unique (like sankofa-market-a1b2c). That's fine — just note down the exact project ID shown, you'll need it later.
📊 Google Analytics (Optional)

You can enable Google Analytics if you want to track visitors. It's free. Or you can skip it for now and enable it later.

✅ Click "Create project"

Firebase will take about 30 seconds to set up your project. Once done, click "Continue".

🎉
Important: On the project dashboard, you'll see your Project ID (something like sankofa-market or sankofa-market-a1b2c). Write this down! You'll need it in Step 4.
2

Enable Firebase Services

⏱ ~5 minutes

Sankofa Market uses 4 Firebase services. Enable each one from the left sidebar in your Firebase Console:

🔐 Enable Authentication

Click Authentication in the left sidebar → Click "Get started" → Go to "Sign-in method" tab and enable:

ProviderSettings
📧 Email/PasswordEnable ✅
🔵 GoogleEnable ✅ — Add your email as support contact
📱 PhoneEnable ✅ — For SMS verification (optional)
🗄️ Enable Firestore Database

Click Firestore Database in the left sidebar → Click "Create database"

  • Choose "Start in production mode"
  • Select location: europe-west1 (closest to Ghana 🇬🇭)
  • Click "Enable"
📁 Enable Storage

Click Storage in the left sidebar → Click "Get started"

  • Choose "Start in production mode"
  • Select the same location as Firestore
  • Click "Done"
🌍 Enable Hosting

Click Hosting in the left sidebar → Click "Get started"

  • You'll see setup instructions — don't follow them yet!
  • Just click "Next" through the wizard until you see "Finish"
  • Click "Finish" (we'll deploy properly in Step 5)

Get Your Firebase Config

⏱ ~2 minutes

⚙️ Go to Project Settings

Click the ⚙️ gear icon (top left, next to "Project Overview") → Click "Project settings"

📱 Register a Web App

Scroll down to "Your apps" section → Click the Web icon </>

  • App nickname: sankofa-market-web
  • Don't check "Firebase Hosting" (we'll handle that separately)
  • Click "Register app"
📋 Copy Your Config

You'll see a code block with your Firebase config. It looks like this:

Your Config (example) const firebaseConfig = {
  apiKey: "AIzaSy...your-key-here",
  authDomain: "sankofa-market.firebaseapp.com",
  projectId: "sankofa-market",
  storageBucket: "sankofa-market.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};
⚠️
Copy the ENTIRE config block (the firebaseConfig object with all its values). You'll paste it in the next step. Do NOT close this page yet!
📝 Update the Config File

Open the file config/firebase-config.js in the Sankofa Market project and replace the placeholder values with your actual config:

config/firebase-config.js // Replace these with YOUR actual values from Firebase Console

4

Generate Firebase CI Token

⏱ ~2 minutes — This lets us deploy from Arena

🔑
What is a CI Token? It's a special authentication token that allows Firebase deployments without interactive login. You generate it once on your computer, then paste it here so I can deploy your site.
💻 Open Command Prompt on your Windows PC

Press Windows Key + R → Type cmd → Press Enter

⚡ Run this command

Copy and paste this entire line into Command Prompt, then press Enter:

npx firebase-tools login:ci

If it asks to install firebase-tools, type y and press Enter.

🌐 Sign in with your Google account

Your browser will automatically open a Google sign-in page. Sign in with the same Google account you used to create the Firebase project. Click "Allow" to grant permissions.

🔑 Copy the token

After signing in, go back to Command Prompt. You'll see a long token like this:

// It will look something like this:
✔  Success! Use this token to login to the firebase CLI:

1//0abcDEFghijklMNOpqrSTUvwxYZ1234567890abcdef...
📋
Copy the entire token (the long string starting with 1//). Right-click in Command Prompt to paste it, or select it and press Ctrl+C. You'll paste this token in the next step.

Troubleshooting

Common issues and solutions

❌ "npx is not recognized"

This means Node.js is not installed. Download and install it from nodejs.org (choose the LTS version). After installing, close and reopen Command Prompt, then try again.

❌ "Error: Authentication required"

The CI token may have expired or wasn't copied correctly. Generate a new one by running npx firebase-tools login:ci again. Make sure to copy the entire token string.

❌ "Project not found"

Double-check your project ID. Go to Firebase Console → ⚙️ Project Settings → look for "Project ID" at the top of the General tab. It might be different from the project name.

❌ Browser doesn't open for login

Command Prompt will show a URL. Copy that URL and paste it into your browser manually. Complete the sign-in, then go back to Command Prompt.

⚠️ "npm WARN deprecated" messages

These are just warnings and can be safely ignored. They don't affect the token generation.
